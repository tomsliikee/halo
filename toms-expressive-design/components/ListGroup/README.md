# ListGroup

Rows that belong together, stacked 4px apart. The group's outer corners are 24px and every inner corner is 8px, so the rows read as one block.

- Each row has a bold label on the left and a value or `control` (e.g. a `Switch`) on the right, plus an optional `progress` (a `WavyProgress`) and a note line.
- `highlight` paints one row `--primary-container` to mark the current or most important item.
- Use it for settings, goal lists and the parts of a score.
