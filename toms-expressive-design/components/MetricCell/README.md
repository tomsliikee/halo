# MetricCell

A cell of the metric grid: a 108px disc or a 108px-tall card, two per row, 12px apart.

- Rows alternate disc + card, then card (as a `pill`) + disc, which gives the grid its rhythm.
- A disc cell is a tone container with the value in the accent and a label under it.
- A card cell is `--surface-bright` with the label above, the value in 26px/800, and an optional note ("Best so far", "at 08:20").
