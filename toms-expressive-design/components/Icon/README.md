# Icon

Material Symbols Rounded, 24px by default, drawn in `currentColor`.

- Selected navigation uses filled icons; elsewhere, prefer the outlined forms from Material Symbols when you add new ones.
- In tiles and list items an icon sits at half size on a 40px `ShapeBadge`.
- Pass `label` only when the icon stands alone and carries meaning.
- The bundled set is in `window.Toms.icons`. Extend it with any Material Symbols path.
