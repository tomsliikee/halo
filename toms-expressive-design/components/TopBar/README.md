# TopBar

The title area of a top-level screen: the screen name in `display`, a subtitle in `subtitle`, and up to two round actions on the right.

- The title stays light (450) so the screen's main metric leads.
- Over a dark header image or illustration, pass `ink` (white); the subtitle then takes the ink at 80 %.
- Sub-screens drop the subtitle and add a back `IconButton` above the title.
