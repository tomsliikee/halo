# IconButton

A round 48px button for back, edit, close and similar actions at the top of a screen or over imagery.

- `--surface-container-highest` with `--shadow-button` when floating. `flat` drops the shadow for use inside cards.
- Back sits top-left at 16px from the edges; secondary actions sit top-right, 8px apart.
- The consumer provides `label`, which is required because the button has no visible text.
