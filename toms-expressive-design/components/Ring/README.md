# Ring

A circular progress for one or two goals, with a value or note in the centre.

- 170px with a 12px round-capped stroke, starting at 12 o'clock and running clockwise. The outer ring is `--primary` on `--primary-container`; the optional inner ring is `--secondary` on `--surface-container-highest`.
- The centre disc is `--surface-container-low`, holding a `metric-m` value and a `label`.
- A 36px ring with a 5px stroke works as a progress glyph in a tile header.
