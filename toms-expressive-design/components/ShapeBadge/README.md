# ShapeBadge

An M3 Expressive shape that carries a value, an icon or an avatar. Its form grows more pronounced as the value grows.

- Pick a **mood** per section: `soft` (circle to flower), `radiant` (circle to very sunny cookie), `angular` (square to boom) or `warm` (circle to heart). `level` (0–1) selects one of five steps, in fifths.
- Sizes: 116px for a screen's hero value (`size-hero-badge`), 44px in list items, 40px as an icon badge.
- Fill with a tone (`--tertiary`, `--secondary`…) and its `on-` colour. For a judged value, use `--status-good`, `--status-warn` or `--status-bad`.
- Fixed `shape` works for avatars and logos-in-shape (e.g. `cookie9` with a person icon).
- Shapes are polar approximations of the M3 Expressive set.
