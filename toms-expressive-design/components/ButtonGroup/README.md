# ButtonGroup

A connected group for choosing one of two to four options: a period, a view, a theme.

- Segments are 2px apart. Outer corners are full and inner corners 8px. The selected segment turns `--primary` and springs to fully round.
- Use the 56px size on settings screens and `small` (40px) inside cards.
- Labels are one or two words. Use it only when every option fits on one line at 360px width.
