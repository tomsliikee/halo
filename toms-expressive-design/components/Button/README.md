# Button

A 56px pill for the action that moves a flow forward.

- `filled` (`--primary`) for the main action and `tonal` (`--primary-container`) for a secondary one. Use one filled button per view.
- Full width at the bottom of a step-by-step flow, inset 16px.
- The label is a short verb in sentence case at 16px/600: "Next", "Save", "Start".
