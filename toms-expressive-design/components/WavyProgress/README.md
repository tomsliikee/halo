# WavyProgress

The expressive linear indicator for any "x of y": a wave for what is done, a straight track for what remains, and a stop dot at the end.

- Wave amplitude is 3, wavelength 19, stroke 4 with round caps, and there is a 9px gap before the track.
- Colour is the section's tone. The track is the same colour at 22 %.
- Put the label on the left and "x of y" on the right on the line above, at 14px.
- Use `--status-*` colours only when the bar judges a value against a range.
